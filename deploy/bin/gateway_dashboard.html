Glossary every term on this page

Lane
one concurrent request slot the gateway lets onto the local engine. “Budget” is how many exist.
Engine running / waiting
requests the vLLM engine is generating for right now / holding in its own queue.
Prefill
the engine reading a prompt before it can write the first word. Slow for long prompts.
Decode
the engine writing the answer, one token at a time.
tok/s
tokens per second. A token is about 3/4 of a word.
TTFT
time to first token: how long until the answer starts appearing.
Inter-token latency
gap between tokens once streaming has started.
p50 / p95
the typical request, and the slowest 1 in 20.
KV cache
the GPU memory holding every in-flight conversation. Full = nothing more fits.
Prefix cache hit
part of a prompt the engine had already computed and reused instead of recomputing.
Token budget
cap on prompt+output tokens reserved across all lanes at once; protects the KV cache.
Remote / overflow
the paid provider. Used as a valve for spikes and planned local-offline windows, not the normal path.
Local-offline window
a planned period (benchmark, engine restart) when new work goes remote instead of being refused.
Work class
who a request is for: kevin (interactive) > halo > runner > background. Higher classes are served first; each lower class may only leave a bounded prefill backlog.
Share / ceiling
a class’s weight when classes compete / how much engine backlog it may leave queued.
Perf breaker
a safety that sends new work remote while the engine is saturated (queue, GPU, or cache pressure).
Held / rejected
background work paused until local recovers (never billed) / refused outright during a deliberate remote window.
